Hash Algorithm Comparison

AlgorithmOutput LengthSecuritySpeedCommon Use
MD5128-bit (32 hex)BROKENFastestLegacy checksums only
SHA-1160-bit (40 hex)DEPRECATEDFastGit commits (legacy)
SHA-256256-bit (64 hex)SECUREModerateTLS, blockchain, signatures
SHA-512512-bit (128 hex)SECUREModerateHigh-security, HMAC

Why MD5 & SHA-1 Are Deprecated

  • MD5 collisions demonstrated in 2004 (Wang et al.)
  • SHA-1: Google SHAttered attack (2017)
  • NIST deprecated SHA-1 for signatures in 2011

Why SHA-256/512 Are Preferred

  • No known practical collision attacks
  • SHA-2 family, NIST standardized (FIPS 180-4)
  • Used in Bitcoin, TLS 1.3, certificate chains

Password Entropy Explained

Entropy measures randomness and unpredictability in bits. Higher entropy = exponentially harder to brute-force.

Entropy = L × log₂(R)

R = character set size  •  L = password length  •  Each added bit doubles the search space

Character Pool Sizes

Lowercase [a-z]+26
Uppercase [A-Z]+26
Digits [0-9]+10
Symbols [!@#$...]+32
Full pool= 94
